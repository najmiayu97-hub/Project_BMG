# Introduction

## About the BMG Website

**Berkah Media Gemilang (BMG)** is an event planning agency and creative partner based in Bandung. This website is a company profile designed to share company information, services, project portfolio, and contact details with visitors.

The website is developed to be responsive, interactive, and to have a clean, easy-to-use interface.

## Project Overview

This project focuses on developing a company profile website with the following features:

- Home page with hero, about, services, portfolio, clients, reasons, process, testimonial, and CTA.
- About Us page with vision, mission, values, statistics, and team.
- Services page with a catalog of 6 services and the work approach.
- Portfolio page with event category filters.
- Contact page with a form and contact information.

## Development Technologies

- **React.js 19** – Building the user interface.
- **Vite 8** – Development server and build tool.
- **JavaScript (ESM)** – Website logic and interactions.
- **CSS** – Styling and layout per component.
- **VitePress 1.6.4** – Project documentation.
- **Oxlint** – Code linting.

## Documentation Purpose

This documentation provides a comprehensive overview of the BMG website, including project structure, installation, page descriptions, features, styling, language configuration, and deployment.
