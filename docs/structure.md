# Project Structure

Project BMG dikembangkan menggunakan React
dengan struktur folder yang memisahkan
komponen, halaman, stylesheet, dan aset.

## Source Folder

Folder `src` merupakan direktori utama
yang menyimpan kode aplikasi.

### Main Files

- App.jsx: Komponen utama aplikasi.
- main.jsx: Entry point aplikasi React.
- App.css: Styling utama aplikasi.
- index.css: Global styling.

### Page Components

- AboutUs.jsx: Halaman About Us.
- Services.jsx: Halaman Services.
- Portfolio.jsx: Halaman Portfolio.
- Contact.jsx: Halaman Contact.

### Language Components

- language.js
- LanguageProvider.jsx
- LanguageSwitcher.jsx

File tersebut digunakan untuk
mengatur fitur pergantian bahasa.
